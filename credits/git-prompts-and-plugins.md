Section: Projects whose ideas we follow
- [Oh My Zsh](https://github.com/ohmyzsh/ohmyzsh)'s git plugin (MIT), whose
  abbreviations Nukesh offers by the same names, and
  [Starship](https://starship.rs), [powerlevel10k](https://github.com/romkatv/powerlevel10k)
  with gitstatusd, and [git's own prompt script](https://github.com/git/git/blob/master/contrib/completion/git-prompt.sh),
  whose prompts showed what a repository's state looks like at a glance
  ([ADR 0288](docs/adr/0288-git-in-nukesh.md)).
